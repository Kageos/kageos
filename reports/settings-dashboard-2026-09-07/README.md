# 系统设置改造验收

2026-09-07 · 本地源码实现与验证完成，未发布或重启线上服务。

## 已实现

- 日志归档：system 管理员可手动重试；定时与手动执行互斥；失败退避；失败批次不阻塞其他批次。完整对象 SHA-256 与大小校验通过并保存上传检查点后，才清理选中的源日志。
- 恢复边界：支持部分清理后续跑、清理完成但状态写入失败后的收尾、已有验证证据的旧失败批次，以及完成后的幂等重试。
- 数据库：7 天 / 30 天自然日窗口，分类及单库筛选，折线 / 柱状 / 明细切换。发现已配置 MySQL 实例内可见的非系统库，并展示未归属库；以实例 UUID 和库名区分身份，避免不同实例同名库被合并。
- 数据完整性：不把缺失采样画成 0，不跨缺失日期计算日增长，不把盘点口径升级算成真实增长；完整日快照不会被失败补采覆盖。旧快照没有实例身份时不猜测单库归属。
- 文件资产：重做指标与列表间距，增加缩略图视图，保留详情、预览、下载和审计入口。
- 调用量与运行状态：调整指标卡、趋势图、排行和深浅主题样式；运行总览加入资源趋势；调用量可切换图表；阻止旧筛选请求覆盖新结果。

## 运行环境边界

源码改造不等于线上失败批次已恢复；本次没有触碰生产日志、备份对象或部署状态。更新运行版本后，需核对原失败批次的错误与对象状态，再使用“立即重试”验收真实恢复。

自动重试的时间是最早可执行时间，实际由后续归档调度触发。日志归档属于操作日志转存，不是整库备份。未配置的数据库实例不在盘点范围内。
